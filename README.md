# Semaine en équilibre

Un agenda hebdomadaire simple pour répartir école, voyages, moments spirituels et sport.

## Ce que l’application sait faire

- Parcourir les semaines et revenir à la semaine en cours.
- Ajouter, modifier et supprimer des activités avec un jour, des heures, un lieu et une note.
- Filtrer par catégorie et voir le nombre d’activités de chaque catégorie.
- S’adapter aux écrans mobiles et aux ordinateurs.

## Données et confidentialité

L’application enregistre les activités dans le stockage local du navigateur (`localStorage`). Elle ne les envoie pas à GitHub ni à un serveur. Elles restent sur le navigateur et l’appareil utilisés : elles ne se synchronisent pas entre appareils. Effacer les données du navigateur peut supprimer le planning.

Le code du dépôt est public. N’y ajoutez pas de vrais horaires, adresses ou informations personnelles.

## Publier avec GitHub Pages

Le workflow `.github/workflows/pages.yml` publie automatiquement le site à chaque mise à jour de `main`.

Pour l’activer la première fois :

1. Ouvrir **Settings → Pages** dans ce dépôt.
2. Dans **Build and deployment**, choisir **GitHub Actions** comme source.
3. Ouvrir l’onglet **Actions** et vérifier le déploiement.

L’adresse du site sera normalement :

`https://Joel237-code.github.io/semaine-en-equilibre/`
